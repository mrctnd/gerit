# Güvenlik politikası

## Desteklenen sürümler

Gerit henüz `0.x` geliştirme aşamasındadır. Güvenlik düzeltmeleri yalnızca en güncel sürüm için yayımlanır.

## Güvenlik açığı bildirme

Güvenlik açığını herkese açık issue olarak paylaşmayın. GitHub deposundaki **Security → Advisories → Report a vulnerability** yolunu kullanın. Raporunuza etkilenen sürümü, tekrar üretme adımlarını, olası etkisini ve varsa önerdiğiniz düzeltmeyi ekleyin.

ntfy konu adlarını, `.env` içeriklerini, şirket alan adlarını veya gerçek görev verilerini rapora koymayın. Alındı onayı ve ilk değerlendirme için yedi gün hedeflenir; düzeltme zamanı etkinin ciddiyetine göre belirlenir.
