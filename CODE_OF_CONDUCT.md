# Topluluk davranış kuralları

Gerit topluluğunda saygılı, yapıcı ve kapsayıcı bir çalışma ortamı hedeflenir.

- Fikri eleştirin, kişiyi değil.
- Ayrımcı, aşağılayıcı, tehditkâr veya taciz edici davranışta bulunmayın.
- Hata raporlarında özel verileri, erişim anahtarlarını veya şirket bilgilerini paylaşmayın.
- Geri bildirimi somut, uygulanabilir ve iyi niyetli biçimde verin.

Uygunsuz davranışları depo sahibine GitHub üzerinden özel olarak bildirin. Proje yöneticileri, topluluk güvenliğini korumak için içerik kaldırabilir veya katılımı sınırlandırabilir.
